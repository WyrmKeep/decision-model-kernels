# GPU-minute estimate (sequential; server start and stop included). Observed: startup_s of 12 runs in the data set data/2026-10-30-window1 = 3.6-5.6 s (one 9.6 s); long3q mean latency 787 ms
# (shape census, harness/profile/census); short requests 37 ms and about 95 ms. Everything else is [INFERENCE]: client container start 2 s, teardown + log copy 5 s, nsys start 15 s (about 3x the
# unprofiled start), nsys stop + report write 45 s (15-60 s; about 70,000 kernels plus OS-runtime records), nsys inflation of long requests 3 %.
#   timing run : start 5.6 s (worst observed 9.6 s) + client start 2 s + (2 warm-up 0.13 s + 11 x 0.787 s = 8.8 s) + stop and copy 5 s = 21.4 s = 0.36 min (worst 25.4 s = 0.42 min)
#   nsys run   : start 15 s + client start 2 s + (8.8 s x 1.03 = 9.1 s, rounded up to 10 s) + stop and report 45 s + copy 5 s = 77 s = 1.3 min
#   sum        : 2 x 0.36 + 2 x 1.3 = 3.3 min nominal (lines 1-3 only: 2.0 min); 4.5 min with a safety factor 1.5 on both nsys runs: inside the 5 min of the package.

# hung stop costs at most 3 minutes, and 180 s is four times the 45 s assumed above) and --force-overwrite=true in the nsys wrapper (a repeated run replaces a leftover report instead of failing at start).
